# 웹사이트 제작과 배포 IT 용어 가이드

시니어와 웹 초보자가 웹사이트 제작·배포 용어를 쉽게 익힐 수 있도록 만든 독립형 교육용 랜딩페이지입니다.

## 파일

- `it-glossary.html`: 본문, 디자인, 검색, 체크리스트, 인쇄 기능이 포함된 단일 HTML
- `vercel.json`: Vercel 루트 주소를 안내 페이지로 연결하는 설정

## 로컬 미리보기

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/it-glossary.html`을 엽니다.

## 원문 정보

제작 요청에 안내서 원문과 제공자·저작권·원문/보완 날짜가 포함되지 않아 페이지에는 확인 필요 상태로 표시했습니다. 해당 정보는 원문을 받은 뒤 정확한 문구로 보완해야 합니다.
