01 · Process

사이트가 세상에 나오는 순서

내 컴퓨터에서 고친 파일이 곧바로 인터넷에 보이는 것은 아닙니다. 저장하고, 변경 기록을 남기고, 원격 저장소로 보내고, 배포해야 방문자가 새 화면을 볼 수 있습니다.

코드 작성

HTML·CSS·JavaScript 파일을 만들거나 고칩니다. 아직은 주로 내 컴퓨터 안의 작업입니다.

커밋

어떤 파일을 왜 바꿨는지 한 묶음의 변경 기록으로 저장합니다.

푸시

내 컴퓨터의 커밋을 GitHub 같은 원격 저장소로 올립니다.

배포

저장소의 코드를 방문자가 접속할 수 있는 웹사이트로 공개합니다.

운영

주소·보안·내용·접속 상태를 살피며 사이트를 계속 관리합니다.

꼭 기억하기: 커밋은 변경 기록을 남기는 일입니다. 커밋만 해서는 공개 사이트가 바뀌지 않습니다. 보통 푸시와 배포까지 완료되어야 합니다.
